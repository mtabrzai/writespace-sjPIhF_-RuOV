## [1.0.0] - 2024-04-05

### Added
- Initial project release
- User authentication (login/register)
- Blog post management (create, read, update, delete)
- Admin dashboard for user management
- Responsive design with Tailwind CSS
- Dark mode support
- Distraction-free writing interface
- Zustand state management
- React Router for navigation
- Vitest and Testing Library for testing
- API integration with environment configuration
- Reusable UI components (Button, Card, Avatar)
- Route guards for private and admin routes
- Form validation and error handling
- Loading states for async operations
- Pagination support for blog posts and users
- TypeScript type definitions for core entities
- Project documentation (README.md)
